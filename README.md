# اختبار تدريب التواصل الفعال | Effective Communication Training Assessment

تطبيق ويب ثنائي اللغة (العربية والإنجليزية) يتضمن اختباراً قبلياً (اختيار من متعدد) وآخر بعدياً (صح/خطأ)، ويعمل كتطبيق قابل للتثبيت (PWA).

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub الخاص بك.
2. من **Settings → Pages** اختر النشر من فرع `main` والمجلد `/root`.
3. بعد الحفظ، شارك رابط GitHub Pages الذي يظهر لك.

## استخدام المتدرب

يفتح المتدرب الرابط، يختار اللغة ونوع الاختبار، ثم يكتب اسمه. بعد إكمال الأسئلة يمكنه إرسال النتيجة عبر واتساب برسالة جاهزة.
